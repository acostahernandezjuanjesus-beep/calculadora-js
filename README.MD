# Calculadora JS

Calculadora funcional construida con HTML, CSS y JavaScript puro.

## Funcionalidades
- Operaciones básicas: suma, resta, multiplicación, división
- Porcentaje y cambio de signo
- Historial de operación en pantalla

## Stack
- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript ES6

## Cómo correrla
Clona el repo y abre `Index.html` en tu navegador.
